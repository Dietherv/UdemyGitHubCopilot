# Word Counter Project

This project is a simple Python application that counts the number of words in a given text input from the terminal.

## Purpose

The purpose of this project is to demonstrate how to handle user input in Python and perform basic text processing.

## How to Run

1. Ensure you have Python installed on your machine.
2. Navigate to the project directory.
3. Run the following command in your terminal:

   ```
   python src/main.py
   ```

4. Follow the prompts to enter your text. The application will display the word count.
