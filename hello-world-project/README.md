# Hello World Project

This project is a simple Python application that displays "¡Hola, mundo!" when executed. 

## Purpose

The purpose of this project is to demonstrate the basic structure of a Python application and how to define and call functions.

## How to Run

1. Ensure you have Python installed on your machine.
2. Navigate to the project directory.
3. Run the following command in your terminal:

   ```
   python src/main.py
   ```

This will execute the `main.py` file and display the greeting message.
